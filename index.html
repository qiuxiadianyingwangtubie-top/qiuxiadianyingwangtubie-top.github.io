// NOTES · 老片观察

🎞️

《活着》—— 一个人扛住四十年

张艺谋把余华的小说拍成了福贵的一生。葛优把一个被时代反复碾压却还活着的小人物演得入木三分，最后那句"活着就好"让多少人红着眼走出放映厅。

经典值：★★★★★ // 正版可核
🎬

《英雄本色》—— 一把钞票一把火

1986 年吴宇森把小马哥和小马哥的风衣一起烧进了港片史。慢动作、双枪、教堂白鸽，这些后来被抄了无数次的镜头，源头都在这儿。周润发从此是"发哥"。

经典值：★★★★★ // 正版可核
🌊

《悲情城市》—— 沉默的家族史诗

侯孝贤用长镜头和台语、上海话、日语的混杂，讲一个家族在二二八前后的命运。全片克制到几乎不表态，却比任何控诉都沉重。看修复版，字幕都值得细读。

经典值：★★★★★ // 正版可核
